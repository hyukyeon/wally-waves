# t14_aes: Zkne/Zknd: AES-128 암호화 (FIPS-197 부록 C.1 벡터)
# 명세 의사 코드에 따라 aes64esm/aes64es 로 라운드를 만들고, 라운드 키는 파이썬이 같은 배치로 만든 값을 쓴다.
# 배치: 열 c 를 레지스터 슬롯 perm[c] 에 두고 각 열의 바이트 순서를 뒤집는다 (파이썬 탐색으로 찾은 배치).
# 덧붙여 aes64ks1i, aes64ks2 의 결과를 명세 의사 코드로 계산한 값과 비교한다.

.section .text.init
.option norvc
.globl rvtest_entry_point

  la sp, study_stack_top

  li a0, 0x0123456789ABCDEF

  rdcycle s1
  sub s2, s1, s0

  REPORT_U64 cycles_base, t3
